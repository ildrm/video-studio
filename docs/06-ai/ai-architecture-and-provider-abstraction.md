# AI architecture and provider abstraction

Status: proposed design; not implemented or tested. Owner: AI engineering lead. Dependencies: [canonical model](../03-frontend/canonical-editor-state-and-schema.md), [feature catalog](../01-product/feature-catalog.md), [release gates](../09-delivery/phase-gates-and-definition-of-done.md).

Provider safeguards begin in phase 2 for transcription/TTS; advanced semantic workflows remain phase 5. AI is optional, asynchronous, provider-agnostic and scoped to tenant-authorized asset versions. A typed gateway routes speech recognition, word alignment, diarization, TTS, translation, video understanding, highlight ranking, tracking, segmentation, separation, natural-language editing and generation to versioned adapters. Each request includes purpose, region, consent basis, allowed retention, input references, model configuration and idempotency key. The adapter returns structured result, model/version, time mapping, confidence when actually available, units, usage, warnings and provenance. Missing confidence is `unknown`, never synthesized.

A job validates permission and budget, snapshots input, estimates cost, queues, runs with bounded timeout and retry for transient/idempotent failures, checks output schema and quotas, stores tenant-isolated artifacts, then marks the job completed, failed or cancelled; partial findings are reported as result warnings, not a separate job state. Retry only where provider semantics avoid duplicate charges; reconcile actual usage. Provider selection considers data residency, documented retention, language, availability, quality and cost; fail closed if no eligible provider. Deletion propagates to provider where contract supports it; disclose limitations. Human review precedes application of suggestions and potentially harmful output. P95 latency, accuracy and cost targets are launch gates to measure, not promises. Model upgrades require evaluation and rollback.

Provider errors include unavailable, rate-limited, invalid media, safety refusal, ambiguous result and budget exceeded; no silent fallback to a provider outside the consent or region policy. Never send raw asset paths or credentials to a model. Provider capabilities and contracts must be validated at implementation; no particular vendor is selected.
