# Glossary

Status: proposed • Owner: documentation architect.

**Workspace:** tenant boundary for membership and assets. **Project:** editable creative work owned by workspace. **Revision:** immutable version of project document. **Snapshot:** immutable render inputs including revision, asset versions, preset and build. **Asset version:** immutable uploaded source. **Proxy:** derived media optimized for preview. **Timeline tick:** 1/240000 second; intervals are half-open. **Source PTS:** timestamp in source stream timebase, not frame index. **Job:** durable asynchronous operation with leases and state. **Artifact:** verified output belonging to a job. **Quick Edit:** guided view of the same project. **Pro Editor:** multitrack view. **Approximate preview:** visibly labeled representation whose output may differ from final render. **Tenant:** authorization and storage scope, initially workspace. See [project model](../03-frontend/canonical-editor-state-and-schema.md).
