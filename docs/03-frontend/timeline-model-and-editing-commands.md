# Timeline model and editing commands

Status: proposed • Owner: timeline engineer • Related: EDT-001–006, AUD-001, CAP-001. Dependencies: [schema](canonical-editor-state-and-schema.md).

Timeline ticks are nonnegative JSON-safe integers at 240000/s, with a proposed sequence ceiling of 24 hours. Intervals are `[start,end)`. Source time is integer presentation timestamp PTS multiplied by its rational stream timeBase; clip-local time is timeline minus clip start; playbackRate maps local time to source time. Output frame n begins at nearest-even(n × 240000 × fps.den/fps.num). Compute every boundary from the absolute rational value, never accumulate rounded deltas. At 30000/1001 fps a frame is 8008 ticks. V1 frame rates are enumerated in the schema; adding others requires validation.

VFR media uses decoded source presentation timestamps and a source-to-proxy mapping. SourceRange is `[inPts,outPts)` in its declared source timebase, not project ticks. For forward playback, source time = inPts × timeBase + localSeconds × rate. Choose the decoded frame whose presentation interval contains that time; define final-frame hold only within the source interval. Missing/gapped source timestamps require normalization or an explicit warning, never guessed frame indices. Reverse/freeze and nonconstant speed require an extended mapping contract before enabling those features.

At 48 kHz a sample is 5 ticks; at 44.1 kHz it is 800/147 ticks. Compute absolute output sample indices with rational arithmetic and carried remainders; clip splitting must not independently round both sides and duplicate/drop a sample. Quantize visual clip boundaries to output frame boundaries for ordinary edits; audio may be sample-aligned. Subtitles retain tick timing and are rasterized on output frames. Sequence duration is frame-aligned for video export; audio trim follows the same final output duration. Render reports intended and actual quantized duration.

Higher visual track order composites above lower. V1 forbids overlapping clips on one media track unless exactly two clips participate in an explicit transition covering their intersection. Reject triple overlap, ambiguous transition ownership and a transition longer than either clip. Hard cut has no transition object. Caption cues on one language track may not overlap in v1; separate speaker/language tracks support intentional concurrent captions. Audio mute removes a track; if any audio track is solo, only solo, unmuted tracks participate. Visibility affects visuals only; lock prevents edits but does not remove a track from playback/render.

Commands contain commandId, baseRevision, typed operation and affected IDs; inverse/before image is stored in local history. Split requires an interior boundary and preserves continuous source mapping; ripple deletes shift all explicitly targeted downstream tracks atomically or fail if any affected track/group is locked. Never skip a locked track and silently desynchronize it. Roll preserves total span, slip preserves timeline span, slide adjusts neighbors; validate all handles before commit. Insert/overwrite shows affected region; no partial commit. Multi-selection is one transaction. Snapping chooses nearest eligible boundary within a proposed 8 CSS-pixel viewport threshold, ties prefer playhead then marker then clip edge; keyboard frame entry is exact and independent of zoom.

Acceptance: 30000/1001 and 44.1 kHz fixtures split and undo without gap, drift or duplicate sample; source bounds, locks and transition constraints fail atomically. See AT-04 and AT-21.
