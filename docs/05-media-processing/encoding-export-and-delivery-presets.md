# Encoding, export and delivery presets

Status: proposed design; not implemented or tested. Owner: media engineering lead. Dependencies: [canonical model](../03-frontend/canonical-editor-state-and-schema.md), [feature catalog](../01-product/feature-catalog.md), [release gates](../09-delivery/phase-gates-and-definition-of-done.md).

Use versioned presets describing container, codec/profile, dimensions, rational frame rate, pixel format, color, audio layout/rate, bitrate or quality policy, duration and safe-area guidance. Presets are validated against the selected worker build; incompatible input gets explicit conversion or rejection. The initial candidate is SDR H.264/AAC MP4; HEVC, AV1, ProRes and HDR are gated by build, licensing, device and quality validation. Deliver downloadable output only after QC and authorized short-lived access.

An unpinned documentation note lists these candidate template identifiers: `tiktok`, `reels`, `shorts`, `youtube-shorts`, `youtube`, `x`, `linkedin`, `facebook`, `podcast`; it treats `youtube-shorts` as an alias of `shorts`. The list has nine names but includes an alias, so it must not be counted as nine distinct destinations or a verified template inventory. Treat all identifiers as unverified until a pinned file/contract audit; do not use them as product preset IDs. The product also supports a custom preset concept. Confirm actual platform constraints with primary destination documentation, store source and effective date, revalidate on schedule, and expose warnings with no promise of acceptance. No live upload or publishing is implied. Check codec/container compatibility and output dimensions independently. Test CPU and deployment-specific GPU paths separately; toolkit Apple acceleration does not establish Linux GPU support.

The initial product preset ID is `portrait-sdr-mp4`, version 1, as used in the project example. API render requests carry both presetId and presetVersion; stored snapshots resolve the exact configuration. Later platform-named presets require primary destination evidence and their own version history.
