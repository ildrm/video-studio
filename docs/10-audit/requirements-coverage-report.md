The [delivery matrix](../09-delivery/epics-user-stories-and-tasks.md#feature-family-traceability) maps every family to known tasks and proposed acceptance cases; automated checks verify references and acyclic task dependencies.

The proposed v1 core has machine-readable [project](../03-frontend/schemas/project-v1.schema.json) and [snapshot](../03-frontend/schemas/render-snapshot.schema.json) contracts, validated examples and a typed [core OpenAPI](../04-backend/openapi.yaml). The API explicitly marks later sharing and omits unready membership/comment/billing/public-review operations rather than presenting generic objects as complete contracts.
