# Maintenance and evolution

**Status:** proposed. **Owner:** engineering manager with product, media, security and SRE leads. **Scope:** after every release.

Maintain dependency and container inventory, monitor security advisories, patch on risk-based deadlines, re-run media goldens on FFmpeg/build changes, and verify codec licensing and platform delivery presets periodically. Recheck browser compatibility and provider terms/model availability before changes. Track schema and API version usage, publish deprecation windows, and migrate snapshots only with reproducible tests and rollback. Never remove a reader while retained project revisions or render jobs still need it.

Monitor error budgets, queue fairness, artifact failures, storage lifecycle, AI quality drift and cost per verified output minute. Rehearse disaster recovery and incident response, audit privileged access and stale flags, delete expired data under policy and investigate retention exceptions. Backlog defects and accessibility findings with owner and priority; validate fixes against representative fixtures and customer-visible behavior. Review cost, performance and user outcomes each quarter and adjust targets with actual measurements. Architecture changes require an ADR, security assessment and migration plan. Owner transitions include runbooks, dashboards, operational credentials and recovery drills.
