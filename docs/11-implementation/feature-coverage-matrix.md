# Feature coverage matrix

Status: **partial implementation**, updated 2026-10-29. Source of feature definitions and phase/priority assumptions for **every row** is the [canonical feature catalog](../01-product/feature-catalog.md). `P0` is phase-1 foundation, `P1` is initial guided work, and `P2` is later proposed work; priorities are planning assumptions. `IN_PROGRESS` means a partial family, not completion; `NOT_STARTED` means no usable family implementation. No row is marked VERIFIED because the full family and acceptance criteria remain incomplete. Source/test/API/database fields use `—` where there is no implementation.

Subsystem and source legend: **Web** = editor (`apps/web/components/editor.tsx`), dashboard (`apps/web/components/studio.tsx`), uploader (`apps/web/lib/media.ts`), timeline (`apps/web/lib/timeline.ts`); **API** = router (`apps/api/src/server.ts`), media orchestration (`apps/api/src/media.ts`), auth (`apps/api/src/auth.ts`), project validation (`apps/api/src/projects.ts`); **Worker** = media worker (`workers/media/media_worker.py`); **DB** = migrations (`apps/api/migrations/001_foundation.sql`) plus 002 (`apps/api/migrations/002_thumbnail.sql`) 003 (`apps/api/migrations/003_unclassified_media.sql`) and 004 (`apps/api/migrations/004_project_archive.sql`); **Schema** = [v1 project contract](../03-frontend/schemas/project-v1.schema.json); **Infra** = Compose (`docker-compose.yml`) and CI (`.github/workflows/ci.yml`).

Test/evidence legend: **A** = API integration tests (`apps/api/test/integration.test.ts`); **W** = timeline tests (`apps/web/tests/timeline.test.mjs`), upload tests (`apps/web/tests/upload.test.mjs`), project mutation tests (`apps/web/tests/project-actions.test.mjs`), recovery tests (`apps/web/tests/recovery.test.mjs`) and caption tests (`apps/web/tests/captions.test.mjs`); **M** = media tests (`workers/media/tests/test_media_worker.py`); **B** = agent-reported manual browser observation described in [verification](testing-and-verification.md). References show where verification exists, not that every row is fully tested. Earlier evidence may predate later changes; rerun current code.
