# Integration status

Status: **IN_PROGRESS**, local development • Owner: integration lead • Updated: 2026-10-29. See [known issues](known-issues.md) before using any path with real data.

| Boundary | Implemented connection | Evidence / limitation |
|---|---|---|
| Browser → API | Same-origin `/v1` proxy, session cookie and CSRF token; account, workspace, project and media endpoints. | Browser account/project flow observed; authentication is development-only. |
| API → PostgreSQL | Workspace ownership, immutable JSON project revisions, idempotency, upload/asset/job/artifact records and migrations. | The latest seven-test API run passed without skips against disposable PostgreSQL; concurrent migration runners both succeeded with four ledger rows; production RBAC and access reviews remain. |
| Browser → upload API → local filesystem | UI creates chunked session, computes hashes, transfers parts, finalizes; server rechecks bytes and stores immutable local version. | API integration tested with synthetic fixture. The Compose HTTP smoke exercised upload, probe and thumbnail; the actual browser file picker was not yet exercised and retry state is in memory only. |
| API → probe/thumbnail worker | Development supervisor stages input and runs Python/FFprobe/FFmpeg; video thumbnail is verified. | The current 35-test worker suite passed in a restricted Debian container; on the host, 29 passed and six caption tests skipped because drawtext was unavailable, using a test-only shim. There is no durable proxy/waveform pipeline. API integration exercised audio ingestion and a real audio-track mix; the limited background-audio browser workflow remains unverified. |
| Editor → project revision | The editor saves structured v1 documents using ETag and idempotency; one-second autosave and opt-in scoped draft recovery are implemented; unsupported content is guarded. | Browser trim/split/save observed; full timeline parity, advanced data, conflict and accessibility paths need broader testing. |
| Revision → render job → output | Immutable revision snapshot, local job state/lease, bounded worker render, output codec/duration/frame/decode checks, authorized artifact delivery. | API/browser subset observed; one crossfade supported. API integration independently checked H.264/AAC and dimensions for portrait, landscape and square, using the test-only host shim. Local child is not an OS-isolated production worker. Manual captions and rendered-revision playback are implemented; interactive browser verification remains. The latest Compose HTTP smoke exercised caption rendering and download through the web rewrite; this does not verify an interactive browser or production supervisor sandbox. |
| Optional separate worker container | Compose defines a network-disabled one-shot diagnostic profile. | The fresh standalone worker image passed all 35 bundled tests without a bind mount, with network disabled, a read-only root, noexec/nosuid 256 MiB `/tmp`, 2 CPUs and 2 GiB memory. The embedded API supervisor does not automatically use this profile; production isolation and queue integration remain unverified. |
| Providers/publishing/review/billing | No implemented integration. | Keep UI capabilities unavailable until real authorization, configuration and tests exist. |

Relevant implementations: API router (`apps/api/src/server.ts`), media orchestration (`apps/api/src/media.ts`), editor (`apps/web/components/editor.tsx`), client uploader (`apps/web/lib/media.ts`), worker (`workers/media/media_worker.py`). Interface behavior is narrower than the planned [OpenAPI contract](../04-backend/openapi.yaml); do not treat every documented endpoint as implemented.
