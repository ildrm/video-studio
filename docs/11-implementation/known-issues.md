# Known issues and blockers

Status: **open** • Owner: engineering/program lead • Last reviewed 2026-10-29. Do not use this development slice for production customer media.

| ID | Priority | Issue and user/engineering impact | Owner / next action |
|---|---|---|---|
| I-01 | Release blocker | No production identity provider, email verification, reset/MFA or full role model; local authentication is explicitly development-only. | Identity/security: OIDC, real verification/recovery, session rotation, authorization matrix and tenant isolation tests. |
| I-02 | Release blocker | Filesystem storage and embedded child media supervisor have no production-grade network/process isolation, cloud secrets boundary, durable outbox or multi-tenant quotas. | Platform/security: private object storage, isolated workers, resource/network controls, durable scheduling, fairness and abuse tests. |
| I-03 | High | Browser upload/retry is not yet tested through the file picker; in-memory attempts do not survive reload. | Web/QA: verify real picker/resume/cancel, persist non-sensitive recovery metadata and revalidate file hashes. |
| I-04 | High | Local FFmpeg/FFprobe binaries fail to start without a required host library; current worker tests passed with a temporary test-only shim and separately with Debian FFmpeg 5.1.9. | Media/platform: use a properly installed compatible build, verify its codecs and licensing, and rerun tests. |
| I-05 | High | Live preview plays the selected source, not a full composed timeline; rendered-revision playback is available after export. Interactive verification and live parity remain. | Frontend/media: add composition or server preview with parity tests and accessible fallback. |
| I-06 | High | Only limited video tracks, operations and export codecs/presets are supported; the worker rejects many schema-valid advanced documents. | Timeline/media: expand model/typed compiler with explicit capability gating and golden tests. |
| I-07 | High | No generated proxy/waveform, advanced graphics, transcription/narration, provider AI, sharing, publishing or billing; manual captions support only bounded cues and styles. | Product/subsystem owners: implement against documented contracts and individual acceptance cases. |
| I-08 | High | API integration passed a real extra-audio mix; limited browser controls and the browser end-to-end audio workflow are not yet verified. | Audio/media/QA: verify and expand the existing limited controls and persistence; validate playback and real audio+video renders with fixtures. |
| I-09 | High | The current worker suite passed 35/35 in a restricted Debian container; the host passed 29 with six caption skips using a test-only shim. The latest Compose HTTP smoke passed synthetic upload, caption rendering and download through the web rewrite. The fresh standalone image passed all 35 bundled tests without a bind mount under network, filesystem and resource restrictions. Interactive browser behavior, production worker isolation and integration, CI service execution, production deployment, backup/restore and load/scalability remain unverified. | SRE/QA: collect actual build, run, chaos/restore and load evidence with limits and logs. |
| I-10 | Medium | A complete feature-by-feature test/requirement trace, supported browser/device matrix and manual assistive-technology review are absent. | Product/QA/accessibility: expand coverage and run representative tests. |
| I-12 | High | Interactive browser automation is unavailable due to a computer-use startup error; newer lifecycle, recovery, caption, audio and rendered playback workflows remain unverified interactively. npm audit timed out without an advisory verdict. | QA/security: restore browser access, verify those workflows, and rerun dependency audit with a reachable registry. |
| I-11 | Medium | Rec.709-tagged SDR sources are required for the implemented renderer; untagged/HDR/unsupported codecs may ingest but cannot be rendered safely. | Media/product: define explicit source interpretation and supported conversion before enabling. |

See [release readiness](release-readiness.md) and [testing](testing-and-verification.md).
